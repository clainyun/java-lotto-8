# java-lotto-precourse

## 구현할 기능 목록

### 1. 로또 구입 금액 입력 및 검증

- [x] 사용자로부터 구입 금액을 입력받는다
- [x] 구입 금액이 1000원 단위인지 검증한다
- [x] 구입 금액이 숫자가 아닌 경우 예외 처리한다

### 2. 로또 발행

- [x] 1~45 범위 내 중복 없는 6개의 번호를 랜덤으로 생성한다
- [x] 구입 금액에 맞는 개수만큼 로또를 발행한다 (1장 = 1000원)
- [x] 발행된 로또 번호를 오름차순으로 정렬한다

### 3. 당첨 번호 입력 및 검증

- [x] 당첨 번호를 입력받는다
- [x] 입력받은 당첨 번호를 쉼표(,) 기준으로 분리한다
- [x] 보너스 번호를 입력받는다
- [x] 보너스 번호가 당첨 번호와 중복되지 않는지 검증한다

### 4. 당첨 내역 계산

- [x] 각 로또 번호와 당첨 번호의 일치 개수를 계산한다
- [x] 5개 일치 시 보너스 번호 일치 여부를 확인한다
- [x] 각 등수별 당첨 개수를 집계한다

### 5. 결과 출력

- [ ] 구매한 로또 개수와 번호 목록을 출력한다
- [ ] 각 등수별 당첨 개수와 상금을 출력한다
- [ ] 총 수익률을 계산해 소수점 둘째 자리에서 반올림해 출력한다

### 6. 예외 처리

잘못된 입력 또는 로또 생성 오류 시 `IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 메시지를 출력한다.

#### 입력 관련

- [ ] 구입 금액이 1000원 단위가 아닌 경우
- [ ] 구입 금액이 숫자가 아닌 경우
- [ ] 당첨 번호 입력 형식이 올바르지 않은 경우
- [ ] 보너스 번호가 당첨 번호와 중복된 경우

#### 당첨 번호 관련

- [ ] 번호가 6개가 아닌 경우
- [ ] 번호에 중복이 있는 경우
- [ ] 번호가 1~45 범위를 벗어나는 경우

#### 공통 규칙

- [ ] 예외 메시지는 `[ERROR]`로 시작한다
- [ ] 예외 발생 시 해당 입력부터 다시 입력받는다
- [ ] `System.exit()`는 호출하지 않는다

### 7. 프로그래밍 요구 사항

- [ ] indent depth는 2까지만 허용한다
- [ ] 3항 연산자, else, switch/case를 사용하지 않는다
- [ ] 모든 메서드는 한 가지 일만 수행하도록 구현한다 (15줄 이내)
- [ ] Java Enum을 사용해 구현한다
- [ ] 값을 하드코딩하지 않고 상수(`static final`)로 관리한다
- [ ] JUnit 5와 AssertJ를 사용해 단위 테스트를 작성한다
- [ ] UI 로직(System.out, System.in, Scanner)은 테스트에서 제외한다
- [ ] 2주차 피드백을 적극적으로 반영한다
  - [ ] README.md를 상세히 작성한다
  - [ ] 기능 목록을 지속적으로 업데이트한다
  - [ ] 정상·예외 시나리오를 모두 포함한다
  - [ ] 상수를 통해 하드코딩을 제거한다
